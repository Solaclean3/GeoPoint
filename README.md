# GeoPoint Consulting — Website v1

A responsive, lightweight, static website for GeoPoint Consulting. No framework, packages, build process or paid services required.

## Quick start

1. Unzip this folder.
2. Open the folder in Cursor AI.
3. Open `index.html` in a web browser (or use Cursor's Live Server extension for live previews).
4. Edit `index.html` to update wording and sections. Change colours/layout in `assets/styles.css`.
5. Create a new GitHub repository and push the folder contents.
6. Publish through your preferred static hosting provider, or upload these files into your cPanel `public_html` folder.

## Files

- `index.html` — Homepage and all sections
- `assets/styles.css` — Responsive styling
- `assets/main.js` — Mobile navigation and copyright year
- `assets/hero-terrain.svg` — Original illustrative hero artwork
- `assets/contours.svg` — Original topographic illustration
- `assets/favicon.svg` — Temporary GeoPoint icon

## Before going live

- Replace the contact placeholders with an authentic business email and phone number.
- Confirm all advertised services fall within the team's professional competence, insurance and any applicable registration requirements.
- Add actual business information, ABN as appropriate, and verify any professional claims.
- Use project photos only where you hold publication rights; replace illustrative artwork if desired.
- Set up a domain, HTTPS, and verify mobile layout/accessibility and links.
- Consider adding a privacy notice if you deploy analytics or a third-party contact form.
- Review employment-related conflict-of-interest arrangements separately; there is no Byron Shire marketing claim or project reference on this site.

## Publishing with GitHub

This is a static site: GitHub Pages can serve it directly if you enable Pages for the repository. A custom domain is optional. If using cPanel, upload `index.html` and the `assets` folder into `public_html`.
